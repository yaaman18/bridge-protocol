## 支持された主張

1. **π と ρ は一つの損失関係の二つの射影**（`formats.jl` 38〜39 行）。π(u) = L(u)（全ユニットについて記録）、
   ρ(u) = L(u) ∩ M。Lean の Φ = π⋆∘ρ⋆ は和集合、すなわち存在量化の閉包。Ψ と Phi2 = Φ ∩ Ψ の読みも定義と一致。
2. **登録済み profile の重みはすべて +1**、6 ユニット系列には抑制辺がある。`coalition_projection_to_unary_relations
   = "forbidden"` と `loss_sets` の全記録も確認。
3. **単調な基体では C の二つの読みが一致する。** 4 ユニット全列挙 32,768 回路で損失は完全に単調（違反 0）、
   極小集合から読む C と直接読む C の不一致 0。6 ユニット系列では非単調 497 件、不一致 90 件。
   提案者の反証条件2（正の重みだけで非単調が出れば導出は誤り）は発動しなかった。
4. **極小集合から読む C は構成上単調**（違反 0）。直接読む C は混合領域で非単調 100 件。
   Knaster–Tarski を使えるのは前者だけ、という指摘は正しい。
5. **C は縮退を解消する。** Φ_C の包含極小な後不動点に 2 要素以上のものが現れる（4 ユニットで 10,460/18,232 回路、
   6 ユニットで 358/446）。提案者の反証条件1は発動しなかった。
6. **C は冗長性の盲目を解消する。** 複数同時停止でのみ失われるユニットは Φ に一度も入らない（0 件）が、
   C には 12,418/12,478（99.5%）入る。

## 支持されなかった主張

1. **合成の失敗は抑制辺に由来しない。** 重みがすべて +1 の 4 ユニット全列挙でも、84 回路・192 三つ組で
   単独停止の必要性の推移性が破れる。最小例は case 5361（u2 ⇄ u3 の相互ループ）: u2 を止めると u3 が失われ、
   u3 を止めると u2 が失われるが、u2 を止めても u2 自身は失われない。原因は抑制ではなく、
   **停止が出力を止めるだけでユニット自身の更新を止めない**という介入の定義である。
   case 1600 の個別診断（抑制辺の副作用）は正しいが、一般化が誤り。なお case 5361 は既知の限界 (D) と同じ回路。
2. **縮退の機構は無条件には成り立たない。** 「c を止めるとループ全体が止まり c 自身も失われる」は、
   持続ユニットの 34%（22,976/68,332）にしか成り立たない。正しい形は条件つきで、
   κ が Phi2 の後不動点のとき κ には単独で後不動点になる構成素が必ずあり（2,611/2,611）、
   その説明として c ∈ L(c) が 4 ユニットで 2,611/2,611、6 ユニットで 217/220 成り立つ（残余 3 件は未説明）。
3. **ε への相対化は M2・M3 との衝突を解消せず、条件を弱める。** ε-C は naive C より停止する範囲が狭いので通りやすい
   （4 ユニットで 18,232 対 18,031）。ε-C が成り立つ核のうち 75%（13,700/18,232）は Act が空であり、
   蝶番の要求は戻らない。
4. **「三つの症状は同じ根」は一つを取り違えている。** 冗長性は DC の hSelf 側の既知の限界だが、
   組織（hUnit）の側では「冗長に支えられた閉路は組織ではない」とユーザーが 2026-10-02 に決定済み。
   C はこれを「解消」するので、その決定に反する。

## 残る論点（ユーザー判断）

- M1 の「閉包」を必要性（enabling）の閉包として読むか、充足性の含みも入れるか。公開文書は M1 を
  operational closure / precariousness と呼び「維持であって最大化でない」ことを明示するが、
  必要性か充足性かは書いていない。文献（Di Paolo, Thompson）の定式化はこのリポジトリからは検証できない。
- 充足性の読みを **hUnit** に入れる案は上記のとおり劣る。他方 **hSelf** の冗長性の限界に対しては
  C が有効（12,418/12,478）なので、適用先を hSelf に絞った比較記録は検討に値する。これは提案者の「記録案」と
  同じ方向だが、適用先が違う。

phenomenal_claim = not_certified。有限の探索結果であり、一般の不可能性は示していない。

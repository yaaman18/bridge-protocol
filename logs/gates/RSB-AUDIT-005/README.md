# RSB-AUDIT-005 — 背景が変わると独立性も変わる

2026-09-10、M2をDCとは別の背景条件として検査し、随伴の破れを具体的なN/Xで表示した。
`G3-background-20260910.log` は38/38、出力は `background-examples.toml`。

| モデル群 | M2 | DCの条件分離 |
|---|---|---|
| M2背景を保つ抽象関係5例 | 全例成立 | 全条件と各1条件の不成立を構成 |
| 最初の6ユニット測定例 | 成立 | 全4条件成立 |
| 今回の測定分離corpus5例 | 全例不成立 | DC単独では各pattern成立 |

測定corpusのM2反例はいずれも、α像が空の出力mについてN={m},X=∅としたもの。
α*(N)⊆Xは真だが、存在量化型のσ*は空集合を空集合へ送るためN⊆σ*(X)は偽。
これは「未検査」ではなく、指定された有限関係に対する具体的不適合。
最初の測定例は出力が1つで、そのα像は入力1つ、σはその逆像となり、この問題を持たない。

抽象的なhAct分離ではεをもう一方の入力fiberへ移し、M2を保ってρ*(K)とσ*(ε)を分離した。
hSMC分離ではαの像にない第三の入力をεに含める。これも随伴自体とは両立する。
抽象関係での構成を、そのまま測定からの構成とは扱わない。

## 一入力という背景が生む含意

`formal-experiments/OneInputAdjunction.lean` は次を条件付きで示す。

1. 入力型Eが一要素（Subsingletonかつε非空）、M2随伴が成立するとσ*(ε)=全出力。
2. さらにK非空とhSelfが成立すれば、hSMCとhActがともに成立する。

`G1-20260910.log` で既存Leanをビルドし、`Lean-one-input-adjunction.log` の個別検査がexit 0で通過。
既存 `ERIEC.Adj.rigidity_of_gc` を用い、本体に公理や対象を追加していない。
この背景でhSMCのみ/hActのみを落とすモデルがないのは探索不足ではなく、含意による。
探索の入力数を変えると背景も変わるため、二入力探索はRSB-AUDIT-006として別記録にする。

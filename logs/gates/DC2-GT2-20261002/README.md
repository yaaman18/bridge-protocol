## 検査器の修正（この照合の途中）

組織閉路の判定を「閉路の辺をまとめて除くと全員が持続を失う」から「各辺を単独で除くと終点が持続を失う」に変えた。
まとめて除くと、辺を共有する別の閉路まで壊れ、冗長に支えられた構造を組織と誤認した（例 1713）。
「冗長に支えられた」を辺の水準で読む実装であり、(B) はこの読み方に依存する。

## ユーザー判断が要る点

- (B) 「冗長に支えられた」は辺（経路）の冗長か、部分（供給源のユニット）の冗長か。
- (C) 組織の判定を、発信停止という介入の副作用込みで定めてよいか。
- (D) 運動ユニットを止めたとき、その行為は（ユニットの状態にかかわらず）失われたと読むべきか。測定の写像の変更にあたる。

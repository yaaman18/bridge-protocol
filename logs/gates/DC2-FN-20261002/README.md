## 結果

1. **ラベルは正しい**: 15型すべてで、辺を除くと持続が壊れる閉路（弱い読み）が埋め込み閉路と完全に一致。
2. **偽陰性は本物**: 直接再計算でも N3 の量化式は偽。
3. **原因1（運動ユニット経由の制限）を確認**: 力学と κ を変えずに b を運動ユニットと宣言すると N3 は真になる。
4. **原因2（十分な供給源が2つ）を確認**: 冗長ハブでは b・c を単独で止めても何も失われず、a は {b, c} の同時停止でのみ失われる。
   冗長な辺を除くと対が見つかる。
5. **窓に依存しない**: P・H・L・R の 72 通りで、偽陰性3型はどれも真にならない。
6. **網羅照合（弱い読み）**: 計 52,768 回路で**偽陽性 0、誤った対 0**。偽陰性の内訳:

| 領域 | 正 | 偽陰性: 運動経由の制限 | 偽陰性: 同時停止でのみ見える依存 | 偽陰性: 検査器の限界（辺の共有） |
|---|---|---|---|---|
| 4ユニット全列挙 | 7,109 | 21 | 9,670 | 22 |
| 6ユニット系列 | 915 | 336（運動を含まない閉路 120 + 全ユニットを行為とみなすと解消 216） | 266 | 7 |

厳しい読み（除去で閉路の全員が持続を失う）では偽陽性が 90 と 3 になる。冗長に支えられた閉路を組織とみなさない
読みなので、N3 の誤りではなく読み方の違いとして扱う（個別には未調査）。

## 検査器の修正（照合の途中で行った）

機構レベルの正解は本日作ったもので、凍結していない。食い違いを1件ずつ調べ、検査器の誤りだったものを直した。
- 閉路を κ 内だけで探していた → 遅れて点灯したユニット（5434, 3218）・発振するユニット（4652）を通る閉路を見逃した。全ユニットへ広げた。
- 対の正しさを「同じ単純閉路」で判定していた → ハブを介した相互依存（39）を誤りとした。閉路の連結成分で判定。
- 抑制辺を含む閉路を数えていた → 抑制の解除で持続が壊れるのを「閉路が担う」と誤認（2564）。興奮性の辺に限定。
- 残る限界: 辺を共有する閉路を区別できない（5490）。29 件をこの分類に入れたのは「共有辺がある」という必要条件の判定で、証明ではない。

「同時停止でのみ見える依存」の分類も、閉路上のどれかが2つ以上の同時停止で初めて失われるという弱い判定で、
個別の因果を証明したものではない。

## ユーザー判断が要る点（変わらず）

- 運動ユニットを経ない相互依存を組織とみなすか（ERIE-C の「産出は行為を介する」前提）。
- 冗長に支えられた閉路を組織とみなすか（弱い読みか厳しい読みか）。弱い読みなら、単独停止の測定は
  4ユニット全列挙で組織の過半を見逃す。見えるようにするには複数同時停止から π・ρ を作る必要があり、
  測定プロトコルの変更（N3-RETRACT-PROTOCOL）にあたる。

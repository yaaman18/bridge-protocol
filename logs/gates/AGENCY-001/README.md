## 改訂 2（2026-10-24、ユーザー決定）

ユーザーの決定は二つ。(1) ValueNeeded の除去対象から核のユニットを除く。(2) L3 を、失った構成素を自分の活動で再生成する段
（自己修復、L3R）まで深める。

### 判定の定義（`tools/AgencySubstrate/src/criteria.jl`）

- 価値追跡の除去対象 = 測定で特定した追跡ユニット − 核。測定した追跡ユニットは `value_tracking_measured` として診断に残す。
- 自己修復 `self_repairing`。次がすべて成り立つこと。
  1. L3（`self_producing`）が成り立つ。
  2. 核が空でない。
  3. 核の各ユニット u について、次の手順の結果が修復と判定される。
     - 感覚を止め、資源を潤沢にした条件（日程は宣言した最初の生存日程 `p1-high`。感覚を止めているので日程の影響は収穫だけ）で、
       初期状態から u の発信を `smax × decay_period` 歩止める（u が出す結線が減衰しきる長さ。ここで 32 歩）。定常状態に達してからではない。
     - そのあと止めるのをやめ、さらに `horizon` 歩（60 歩）進める。
     - u の構成素とは、損傷なしで自分の活動だけで動かしたとき最後まで残る、u から出る結線のこと（調べるのは止めた u 自身が出す結線だけ。
       損傷の巻き添えで減衰した他の結線は、生存の確認を通してしか見ていない）。最後に u の構成素すべての強さが 1 以上に戻り、
       かつ系が最後の `alive_window` 歩のあいだ生きていれば、修復とみなす。
  4. 構成素を持つ核のユニットが、少なくとも一つある。
- 損傷は発信停止だけで与える（P-04）。結線の強さを直接書き換える介入は使っていない。
- 量化は「核のすべてのユニット」で、「あるユニット」ではない（P-06）。数値の閾値は新たに置いていない。損傷の長さは、宣言済みの `smax` と
  `decay_period` から導いている。

### この自己修復が示すもの・示さないもの（推論）

- 失った結線は、その両端がほかの経路で活動し続けている場合にだけ戻る（使われた結線が強まる、という規則による）。そのため自己修復は、
  「核のどのユニットの発信を失っても、残りが活動を保つ」という冗長性を要求する。凍結した型と無作為な回路の生成器には自己ループが無く、
  その範囲では 2 ユニットの対からなる核は自己修復しない。ただし、各ユニットが自分自身にも結線を持つ対は自己修復と判定される
  （別コンテキストの検証が指摘し、`self-loop-pair.out` で確認）。自分自身への結線も「残りが活動を保つ」経路になるためである。
- 新しい種類の結線を作ること（宣言されていない結線の生成）は、この基体には無い。ここでいう「生成」は、失った構成素の再生成に限る。

## Lean の定義と Julia の判定の差（別コンテキストの検証で指摘されたもの）

- `SelfProducing`: Lean は、活動を止めた系と元の系を同じ条件の族で比べる。Julia は、止めた側を通常の資源で、残す側を潤沢な資源かつ
  感覚を止めて測る（改訂 1 で「自分の活動だけ」を求めたため）。Julia の残す側は Lean より強い条件である。構造の持続は
  「強さが正の辺が 1 本でも残る」で測っている。
- `ValueDifferentiated`: Lean は Value.lean の内発的な構造的価値（`viabilityContribution`）を使う。Julia は、外から与えた区画の収量を
  価値の代わりにしている。両者の接続は未着手。
- Lean の分離定理は、生存の試行や構造の試行を DC や主体と結び付けていない。述語どうしが独立であることから、ほぼ自明に成り立つ。
- ゲート 2 の資源の帳尻は、一般の場合は不等式（次の資源 ≤ 前の資源 + 収穫 − 活動ユニット数）で確かめている。等号での確認は反射の型 1 本だけで、
  構造の側の保存則の試験はない。
- 自己修復: Lean の `SelfRepairing` は「活動なしでは修復されない」を直接求める。Julia はこれを L3 の成立で代用している（活動を止めれば構造は
  どの条件でも持続しない）。また Julia は「構成素を持つ核のユニットが少なくとも一つある」を追加で求めており、これは Lean の `Nonempty D`
  （損傷の族が空でない）に当たる。
- Lean の `selfProducing_does_not_entail_selfRepairing` は、無関係な二つの試行 t と r について SelfProducing t と ¬SelfRepairing r を示すだけで、
  ほぼ自明である。一つの系についての主張ではない。
- `lean-Agency-revision1.log` と `mutation-revision1.jl`・`mutation-revision1.out` は、10-24 に改訂 1 の記録を複写・改名したもの。
  ファイルの更新時刻は 10-09 の原本の時刻ではない。
- `mutation-before-round3.out` は、第 3 組を足す前の `mutation.out` を、再実行の直前に複写したもの。それを生んだスクリプトは、第 3 組を
  読み込むよう書き換えたので残っていない（違いは読み込む組の数だけ）。第 3 組の型ファイルの冒頭コメントは、これを旧名の `mutation.out` で指している。

# (D) 運動ユニットの行為の読み方の試算 2026-10-02

依頼: 「(D) もテスト環境を用意して試算してみて。ただし判定の定義は私に報告して」（ユーザー）。
既定の測定・`check_dc2` は変えていない。試算用の読み方は `tools/model_audit/GroundTruth.jl` の別関数。

## 判定の定義

測定（既定）: ρ(c) = loss(c) ∩ M、π(a) = loss(a)。loss(u) は u の発信を止めたとき持続を失うユニットの集合。

| 読み方 | 定義 | 関数 |
|---|---|---|
| 既定 | ρ, π は上のとおり | `measure_circuit(...).model` |
| (D) 依頼どおり | ρ'(c) = (loss(c) ∩ M) ∪ ({c} ∩ M ∩ baseline)。運動ユニット a が基点で持続しているなら、a を止めたとき a の行為は失われたと読む。π は既定 | `motor_action_variant` |
| D+self 追加の試算 | ρ' に加え π''(a) = loss(a) ∪ ({a} ∩ baseline)。持続している運動ユニットは自分の行為で産出されたと読む | `motor_self_production_variant` |

照合の正解は v3（`specs/packets/DC2-GROUND-TRUTH-003.md`: 運動を含み、閉路上の各ユニットの停止で次のユニットが
持続を失う興奮性閉路。部分の冗長で読む、決定3・4）。

## 解釈（推論）

- (D) は hUnit を1件も変えない。偽陰性の原因は ρ ではなく π の側（運動ユニットが自分の行為で産出されたと読まれない）。
  GT2 の README にあった「ρ が状態を読む」という説明はこれで訂正した。
- D+self は hUnit の偽陰性を消すが、持続しているすべての運動ユニットが「自分を産出する単元」になる。そのため蝶番なしで
  自己維持する部分が生じ、hHingeNeeded が大量に偽になり、hSelf2・DC2 も大きく動く。DC2 全体の意味が変わる。
- 残る偽陽性（108 / 8、例 6459）は v3 の読み方に由来する: u1 と u4 は互いに不可欠だが、間の経路が別々の中間ユニット
  u2・u3 を通る。中間の部分が冗長なので v3 は組織閉路と認めない。「部分の冗長」を閉路上のすべての部分で見るか、
  対の両端だけで見るかは未決。

# DC2-GROUND-TRUTH-004: 見方2（対の両端だけで部分の冗長を見る）による正解 v4

- 作成: 2026-10-04。根拠: ユーザー決定「見方2の方針で進めてください」（`specs/packets/DC2-HUNIT-N3.md` §6 決定6）
- 15型のラベルは v2（`tools/model_audit/fixtures/organization-ground-truth-v2.toml`、凍結済み）をそのまま使う。
  v4 で変わるのは、網羅照合で使う機構レベルの正解の定義だけ。DC2 の定義（N3）は変えない。

## 機構レベルの組織の対（v4）

κ の異なる2ユニット c, d が**組織の対**であるとは、次のすべてが成り立つこと。loss(u) は u の発信を止めたとき
持続を失うユニットの集合（測定と同じ基点・H・R、単独停止）。

1. **互いにかけがえがない**: d ∈ loss(c) かつ c ∈ loss(d)（決定3: 部分の冗長で読む。決定6: 冗長かどうかは対の両端
   だけで見て、間を中継するユニットの冗長は許す。決定4: 停止の副作用込み）。
2. **依存が行為を経る**（2026-10-04 訂正）: ある運動ユニット a が、相互依存の片方の向きの上にある。すなわち
   「c を止めると a が失われる（または a = c）」かつ「a を止めると d が失われる（または a = d）」、
   あるいは c と d を入れ替えて同じことが成り立つ（決定1: 運動ユニットを経ない相互依存は組織ではない）。

   初版の条件2は「c, d, a が回路の有向グラフの同じ強連結成分に属する」だった。網羅照合
   （`logs/gates/DC2-GT4-20261004/`）で、対に追随するだけの運動ユニット、外から駆動するだけの運動ユニット、
   抑制辺でつながるだけの運動ユニットまで認めてしまい、決定1の「依存が行為を経る」より緩いと分かったので訂正した。

G4(x) = 組織の対が1つ以上ある。

## N3 との関係（推論）

N3 は「c ∈ Φ({d}) かつ d ∈ Φ({c})」、すなわち d を止めると失われる運動ユニット a があり、a を止めると c が失われる
（逆向きも同様）ことを要求する。G4 の条件2は運動ユニットが依存の片方の向きの上にあれば足り、N3 のように両方の向きが
それぞれ運動ユニットの持続を経ることは要求しない。したがって両者の差は、既知の限界 (D)（運動ユニットが自分の行為なしに持続する）に
由来するものと予想する。この予想は網羅照合で検査する。

## 独立性についての注意

条件1は N3 と同じ介入・同じ損失関係を使うので、v4 との照合は N3 の検査としてほとんど独立でない
（`DC2-GROUND-TRUTH-001.md` §5 の「自明な一致」に近い）。N3 の独立な証拠としては、v2 の15型ラベルと辺の除去による
照合（`logs/gates/DC2-GT2-20261002/`）を引き続き使う。

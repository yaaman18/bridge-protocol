# AGENCY-001: 主体性（L2）と構造の自己産出（L3）の監査対象を立てる

- 作成: 2026-10-09（ユーザー決定「L3 まで含めて頑張って実装」。経緯は `docs/10月９日のメモ.md` 114 行目以降と、
  その後の議論。判断は `specs/decision-principles.md` §4 の決定ログ）
- 位置づけ: 新しい研究の筋。DC（自己維持）と `phenomenal_claim`（固定で not_certified）のあいだに、認定可能な
  監査対象を二つ立てる。**凍結した RSB の登録（判定基準パッケージ、profile、解析計画、既知の差分の登録簿）には触れない。**
- 名前: コード上は `Agency`（主体性）と `SelfProduction`（構造の自己産出）。「意識」とは呼ばない（P-11）。
  日本語の正式名は未決（決定ログ）。

## 1. 目的・解く問題

DC を満たすのは安い（数ユニットのラッチで足りる。DC2 の非退化な例は 4 ユニット全列挙だけで 656 件）。
「自律的に自己を維持する何か」に近づけるには、二つの段を足す必要がある（推論）。

| 段 | 内容 |
|---|---|
| L1 | 活動に資源が要り、放っておけば崩れる |
| L2 主体性 | 環境との結合の価値に応じて行為を変え、その調整を除くと生き延びられない |
| L3 構造の自己産出 | 構成素（結線）を自分の活動で維持・生成し、活動が無ければ構成素が崩れる |

「重要に感じられる」（mattering）は別の監査対象として扱い、本作業では主張しない（Value.lean の `MatteringBridge` が要る側）。

## 2. 確認済みの証拠

- 構造的な価値 `viabilityContribution` と `HasStructuralWeight`、現象の述語 `PhenomenalMattering`、架橋 `MatteringBridge`、
  構造から mattering が出ない反例 `no_general_structural_to_mattering`（`formal/ERIEC/Value.lean`）。
- 機能終了 `FunctionalTerminationStep` と永続性（`formal/ERIEC/TemporalDC.lean`）。
- 能力の階層と「生存圧は資源制約として表す」（`category/erie_c_axiom_categorical_memo.md` §12、§12.4）。

## 3. 設計

### 3.1 Lean（`formal-experiments/Agency.lean`、本体から import しない）

- `ValueNeeded`: 宣言した摂動の族 P について、生存が厳密に優越する。
  `(∃ p, 元の系は生存 ∧ 追跡ユニットを止めた系は生存しない) ∧ (∀ p, 止めた系が生存 → 元の系も生存)`。閾値なし（P-05）。
- `ValueDifferentiated`: 構造的価値の異なる二つの結合で、選ばれる行為が異なる。
- `Agent`（構造の名前。監査対象のコード名は `Agency`）: DC と、Value.lean の構造的価値と、上の二条件を束ねる構造。
- `SelfProducing`: 宣言した条件の族 Q について、活動を止めればどの条件でも構造が持続せず、自分の活動があればある条件で持続する。
- 分離定理: 主体性から mattering は出ない、DC から主体性は出ない、DC から構造の自己産出は出ない、主体性から構造の自己産出は出ない。
  いずれも反例モデルによる。**これらは段が論理的に別物であることを示すだけで、中身は測定の側にある。**

### 3.2 Julia の試作基体（`tools/AgencySubstrate/`、ERIEC にも RSB のエンジンにも依存しない独立の試作）

決定的な整数の力学。速い活動と遅い構造の二つの時間尺度を持つ。

- 活動: しきい値網。辺は強さが 1 以上のときだけ働く。
- 資源（L1）: 共有の資源量。活動中のユニットは 1 歩ごとに 1 消費する。運動ユニットは結合した環境の区画から収穫する。
  区画ごとの収量が環境の結合の価値になる。資源が足りなければ全ユニットが止まる（飢餓）。
- 構造（L3）: 両端が活動している辺は強まり（上限あり、資源を使う）、使われない辺は一定の歩数ごとに弱まる。
  活動が無ければ、辺はやがてすべて消える。
- 摂動の族: 区画の収量が時間とともに入れ替わる日程。
- 介入: 発信停止のみ（P-04）。

### 3.3 価値を追跡するユニットの特定（Q2。核の除外は 2026-10-24 ユーザー決定）

設計者が指定しない。「止めると、高収量の区画と低収量の区画の間で運動の選択が変わるユニット」を測定で特定し、
ValueNeeded の除去対象にする。この特定が設計者の指定なしには成り立たないなら、主体性の定式化を撤回する（§6）。

2026-10-24 の決定: 測定した追跡ユニットのうち核に属するものは除去しない。核を止めて系を壊すことで ValueNeeded を見かけ上満たす経路を塞ぐため
（無作為な回路で、主体性の合格 129 件のうち 56 件がこの経路だった）。

### 3.5 L3 の深化: 自己修復（2026-10-24 ユーザー決定）

失った構成素を、自分の活動で再生成すること。損傷は発信停止だけで与える（P-04）。核の各ユニットの発信を、それが出す結線が減衰しきるまで止め、
止めるのをやめたあと、その構成素がすべて戻り、系が生きていることを求める。量化は核のすべてのユニット（P-06）。Lean では `SelfRepairing`
（宣言した損傷の族が空でなく、すべての損傷が自分の活動で修復され、活動なしでは修復されない）。定義の詳細とゲートは
`logs/gates/AGENCY-001/README.md` の「改訂 2」。

### 3.4 正解の型（評価の前にラベルを凍結する、P-06・P-08）

| 型 | 想定 | L2 | L3 |
|---|---|---|---|
| 主体 | 区画の収量を感知して運動を切り替え、自己維持の閉路を持ち、使う辺を維持する | 真 | 真 |
| 反射 | 感知せず、決まった区画を収穫し続ける | 偽 | 真 |
| サーモスタット | 自分の資源量を感知して活動を止めたり始めたりするが、区画の選択はしない | 偽 | 真 |
| 静的な主体 | 主体と同じ配線だが、辺が弱まらない（構造が外から与えられたまま） | 真 | 偽 |
| 閉路なし | 自己維持の閉路が無く、すぐ止まる | 偽 | 偽 |
| 交互 | 発振して両方の区画を収量によらず交互に収穫する（実装時に追加） | 偽 | 真 |

## 4. 仮説・未検証部分

- 試作基体での「生存」は、活動と構造が時間幅のあいだ持続することの代理であり、各時点の DC 判定ではない。
  DC との接続は後の作業（RSB のエンジンで各時点を測る）に回す。
- 正解の型と基体の力学は、同じ設計者（Claude）が書く。型の選び方に、判定の知識が影響している可能性は排除できない。

## 6. 反証条件

- 価値を追跡するユニットが、設計者の指定なしに測定から特定できない → 主体性の定式化を撤回する。
- サーモスタットの型が主体性を満たす → 判別力がない。
- 構造の自己産出が、減衰の速さなどの設計者の調整なしには成り立たない → L3 は調整の産物で、自律の証拠にならない。
- 自己修復が、損傷の長さや観測の時間幅の設計者の調整なしには成り立たない → 自己修復は調整の産物とみなし、撤回する。
- 自己修復を満たす系が、核の冗長性（どのユニットを失っても残りが活動を保つ）以外の性質で区別できない → 自己修復は冗長性の言い換えであり、
  L3 の深化とは呼ばない。

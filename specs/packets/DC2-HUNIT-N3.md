# DC2 の hUnit を相互産出の対（N3）に置き換える決定と、その撤回条件

- 決定日: 2026-09-30（ユーザー決定）
- 対象: `formal-experiments/M1Refinement.lean` の `DC2.hUnit`（DC2 は未批准の実験）
- 証拠: `logs/gates/DC2-AUDIT-20260930/`（`unit-candidates.jl`, `unit-candidates.out`）
- 関連: `specs/packets/RSB-PLAN-002.md` §6c

## 1. 何を変えたか

旧: `hUnit : ∃ U, U ⊆ κ ∧ IrredUnit π ρ U ∧ NonSingleton U`
（κ の中に、2要素以上の既約な自己維持単位がある）

新（N3）: `hUnit : MutualPair π ρ κ`、すなわち
`∃ c ∈ κ, ∃ d ∈ κ, c ≠ d ∧ c ∈ Φ({d}) ∧ d ∈ Φ({c})`
（κ の中に、互いを産出し合う異なる2つの構成素がある）

`IrredUnit` と `NonSingleton` の定義は記録として残し、DC2 からは参照しない。

## 2. なぜ変えたか

測定から得る ρ(c)・π(m) は経路を通じた総効果の損失関係である。閉ループ上の構成素は単独で
ループ全体を「見る」ので、{c} が単独で PostFixed2 になり、既約単位は必ず単元に縮む。
その結果、旧 hUnit は測定回路 52,768 件（4ユニット全列挙 32,768、6ユニット系列 20,000）で一度も
真にならず、DC2 は測定では実現しなかった。

採らなかった案:
- 測定プロトコル（総効果の読み方）の変更 — ユーザーが (a) NonSingleton 側の見直しを選んだ。
- N1（単元の既約単位も認める）— 有限モデルでは `hSelf2 ∧ κ ≠ ∅` と同値になり、条件として空。
  測定領域・抽象担体で「hUnit だけ偽」が 0 件だった。

## 3. 決定時点の数値（撤回条件の基準線）

非退化な case の件数。「hUnit だけ偽」は他の3条件が真で hUnit だけ偽。

| 領域 | 旧 DC2 成立 | N3 DC2 成立 | N3 で hUnit だけ偽 | 核が PostFixed2 で N3 が偽 |
|---|---|---|---|---|
| 測定 4ユニット全列挙（32,768） | 0 | 656 | 114 | 388 / 2,611（14.9%） |
| 測定 6ユニット系列（20,000） | 0 | 111 | 9 | 96 / 734（13.1%） |
| 抽象 C3・M2・E1 全列挙 | 672 | 9,936 | 27,360 | — |
| 抽象 C4・M2・E1 標本 100 万 | 1,011 | 13,630 | 18,437 | — |

Lean 参照模型 M1〜M5 はどの案でも hUnit が真。M1・M5 は DC2 のまま、M2〜M4 の役割も変わらない。

## 5. 実装（2026-09-30）と未検証の部分

実装済み（証拠: `logs/gates/DC2-AUDIT-20260930/lean-M1Refinement-N3.log` ほか）:
- Lean: `MutualPair`、`mem_phi2_singleton_iff`（c ∈ Φ2({d}) ⟺ c ∈ Φ({d}) ∧ d ∈ Φ({c})）、
  `mutualPair_iff`（対があること ⟺ 互いに産出し合う2要素以上の PostFixed2 集合があること）を証明。
  `M1.dc2`・`M5.dc2` を N3 で証明し直し、旧 hUnit の内容は `M1.unit_irred`・`M5.unit_irred` として残した。
  `lake env lean formal-experiments/M1Refinement.lean` はエラー 0、`sorry` 0、公理は propext・
  Classical.choice・Quot.sound の範囲内。
- Julia: `check_dc2` の `hUnit` を MutualPair にし、旧定義は `hUnit_v1` として並記。
- 監査: 直接の量化式との全符号化照合、変異7件の検出、含意行列・分離表を N3 で作り直した。

N3 のもとで新たに分かったこと:
- 既存の測定カタログでも DC2 が成り立つモデルが現れ、`dc2 → hBound`（グラフ境界）に**測定由来の**
  有限反例が出た（`p3-adjoint-without_hBound`, `p6-dc-only-without_hBound`）。解析計画 v1 の誤り1の訂正と整合する。
- `dc2 → hSelf / hSMC / hAct / beta_nonempty` はすべての文脈で前提が充足され、有限反例なし。
- 測定の1入力2運動文脈で、DC2 の全条件と単独脱落4型すべてに非退化な証人がある。

未検証:
- 抽象担体と測定領域の件数は有限の探索結果であり、一般の不可能性・必要性は示していない。
- N3-RETRACT-UNINFORMATIVE は 2026-10-02 に正解照合へ置き換えた。初回の照合結果（偽陰性3件、対の取りこぼし5件）は
  `logs/gates/DC2-GT-20261002/README.md` にあり、扱いはユーザー判断待ち。

## 6. 組織の概念についてのユーザー決定（2026-10-02）

正解照合（`specs/packets/DC2-GROUND-TRUTH-001.md`、`logs/gates/DC2-FN-20261002/`）で見つかった偽陰性2種について:

1. **運動ユニット（行為）を経由しない相互依存は組織ではない。** それは「抽象化された関連性」である。
   ERIE-C の「産出は行為を介する」を組織の要件として保つ。
2. **冗長に支えられた閉路は組織とみなさない。** 閉路の辺を除いたとき、閉路の**全員**が持続を失う場合だけを
   組織の閉路とする（厳しい読み）。

この決定に合わせた正解 v2 は `specs/packets/DC2-GROUND-TRUTH-002.md`。v1 の凍結ラベルは変えない。

追加決定（同日、`logs/gates/DC2-GT2-20261002/README.md` の残る食い違いについて）:

3. **(B) 「冗長に支えられた」は部分（ユニット）の冗長で読む。** 1つの供給源ユニットからの複数経路は冗長ではない。
   閉路上の各ユニットが、閉路上の直前のユニットを止めると持続を失うなら、冗長に支えられていない。
4. **(C) 発信停止の副作用込みで判定してよい**（介入は発信停止のみ、という 2026-09-28 の決定と整合）。
5. **(D) 運動ユニットを止めたときの行為の読み方は既定のまま変えない**（2026-10-03 ユーザー決定）。試算
   （`logs/gates/DC2-D-20261002/`）では ρ を変えても hUnit は変わらず、π も変える読み方は DC2 全体の意味を変えた。
   既知の限界: 運動ユニットが自分の行為なしでも持続する閉路（4ユニット全列挙 48、6ユニット系列 33）は組織として
   検出されない。将来の課題として残す。

正解 v3（部分の冗長による機構レベルの正解）は `specs/packets/DC2-GROUND-TRUTH-003.md`。
6. **(E) 部分の冗長は対の両端だけで見る（見方2）**（2026-10-04 ユーザー決定）。中継するユニットの冗長は許す。
   正解 v4 は `specs/packets/DC2-GROUND-TRUTH-004.md`。互いに守り合う2つの閉路を1つの組織の対として数えること
   （回路 E1）を撤回条件に加えるかは未決。
7. **相互依存が行為を経るのは片方の向きで足りる**（2026-10-04 ユーザー決定、反証可能性を残すため）。正解 v4 の条件2の
   とおり。N3 は両方の向きに行為を要求するので、片方の向きだけの対（6ユニット系列で 16 対）は N3 の既知の限界とする
   （「読み方の差」ではなく N3 の欠陥として扱う、と解釈して記録。ユーザーの訂正があれば改める）。
   既知の差分は種類ごとに登録し、件数を記録する。受け入れ済みの種類は撤回の報告を起こさない。
   既知の差分が食い違いの大部分を占め続けるなら、照合は差分の一覧にすぎなくなっているので、正解の置き方を見直す
   （比率を毎回報告し、判断はユーザーが行う。数値の閾値は置かない）。
